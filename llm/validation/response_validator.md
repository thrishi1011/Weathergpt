# Response Validator Specification & Guardrails

## Overview

The `ResponseValidator` is a deterministic gatekeeper located in `llm/validation/response_validator.py`. It inspects every raw response generated by the LLM before it is returned to the backend or user.

If the LLM response fails any check, the service attempts a single corrective retry. If validation fails again (or if an unrecoverable error occurs), it activates `generate_fallback_response()` to provide a 100% data-grounded response.

---

## Validation Pipeline (Executed in Sequence)

```
LLM Raw Output
      │
      ▼
1. JSON Sanitization & Parsing ──────► (Syntax Error -> Fallback)
      │
      ▼
2. Output Schema Compliance    ──────► (Missing fields -> Fallback)
      │
      ▼
3. Prompt Leak Detection       ──────► (System text leak -> Fallback)
      │
      ▼
4. IMD Alert Verification      ──────► (Phantom alert / Severity mismatch -> Fallback)
      │
      ▼
5. Numeric Grounding Check     ──────► (Hallucinated numbers -> Fallback)
      │
      ▼
Valid Response (Delivered to Backend)
```

---

## Rule Details

### 1. JSON Sanitization & Parsing
- Strips markdown codeblocks (e.g. ````json ... ````).
- Ensures valid JSON object with `answer` string.

### 2. Output Schema Compliance
- Enforces presence of `answer` and `language`.
- Populates `confidence`, `sources`, and `safety_flag`.

### 3. Prompt Leak Detection
- Scans for system prompt keywords (e.g., `"non-negotiable"`, `"few-shot"`, `"system prompt"`).
- Protects internal prompt configuration from surfacing to end users.

### 4. IMD Alert Verification
- **Phantom Alert Prevention**: If `imd_alert.active` is `false`, the response must not claim an active Yellow, Orange, or Red alert.
- **Severity Match**: If an active alert is Yellow, the response must not claim Red/Orange alert.
- Verified across English, Hindi, and Telugu keywords.

### 5. Numeric Grounding Check
- Extracts all numbers in `answer` and verifies their existence in the input payload (`weather_data`, `forecast`, or `user_question`).
- Prevents fabricated temperatures, wind speeds, or precipitation probabilities.
